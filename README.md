# ClassicGames

这是一套练习用的经典小游戏合集。八款小游戏放在同一个 App 里，用来练界面、操作和纪录。不上架，没有上架页，也不提交到 App Store。

## 用 Xcode 打开和跑

1. 安装 Xcode，并打开一次，让它准备好 iOS 模拟器。
2. 双击本目录里的 `ClassicGames.xcodeproj`，或在 Xcode 里选 Open 打开它。
3. 窗口左上角的 scheme 选 `ClassicGames`。
4. 运行目标选一台 iPhone 模拟器。这个工程只做 iPhone，画面锁竖屏。
5. 按 Run（⌘R）。模拟器打开后是首页，点一行就进入那一款。

不需要 CocoaPods，也不需要再装 Swift Package。用到的都是系统框架。
